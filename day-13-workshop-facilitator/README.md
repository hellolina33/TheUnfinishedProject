# Day 13 · Workshop Facilitator

A minute-by-minute team workshop planner, facilitation script builder, and live room timer — all in one local HTML file.

- **3 ready-to-use templates**: 60-min AI Use-Case Sprint, 90-min Team Retro (Sailboat), and 45-min Problem Framing.
- **Run-of-show builder**: add, edit, reorder, and delete timed blocks with block types (Energizer, Solo, Breakout, Plenary, Break), facilitator prompts, board layout notes, live end-time calculation, and a proportional timeline bar.
- **Live Run Mode**: fullscreen room timer with progress bar, current/next block preview, `+2 min` buffer button, keyboard shortcuts (`Space`, `←`, `→`, `Esc`), and gentle Web Audio API chimes at 1 minute left and 0:00.
- **Export & privacy**: Markdown (`.md`) download/copy, printable facilitator sheet (`window.print()`), JSON export/import, `localStorage` autosave, and standalone HTML download.
- English by default, French available.

## Still unfinished
