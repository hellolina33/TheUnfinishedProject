ข้อมูลที่ safa. เก็บและไม่เก็บ

ข้อมูลส่วนตัวและความคืบหน้าของคุณอยู่ในเบราว์เซอร์บนอุปกรณ์ของคุณ safa. ไม่มีบัญชีผู้ใช้และไม่มีเครื่องมือติดตาม

ข้อมูลที่เก็บบนอุปกรณ์

  • เมืองหรือตำแหน่งที่คุณเลือกแชร์ครั้งเดียว เพื่อคำนวณเวลาละหมาดและทิศกิบลัต
  • การตั้งค่า เช่น ภาษา วิธีคำนวณ และธีม
  • กิจกรรมที่คุณเลือกบันทึก เช่น ละหมาด การอ่าน การท่องจำ ละหมาดชดใช้ ดุอาอ์ส่วนตัว และความคืบหน้าในบทเรียน

ข้อมูลที่ไม่เก็บ

safa. ไม่ขอชื่อหรืออีเมล ไม่เก็บสถิติการใช้งานเพื่อการติดตาม ไม่ติดตามโฆษณา และไม่ขายข้อมูล

การเชื่อมต่อภายนอก

เมื่อเล่นเสียง เบราว์เซอร์จะเชื่อมต่อกับ everyayah.com (เสียงอ่านอัลกุรอาน), hisnmuslim.com (เสียงดุอาอ์) หรือ audio.qurancdn.com (เสียงอ่านแต่ละคำ) เมื่อเปิดตัฟซีรภาษาไทย เบราว์เซอร์จะขอข้อความจาก QuranEnc.com บริการเหล่านี้อาจเห็นที่อยู่ไอพีของคุณขณะเชื่อมต่อ

ลิงก์แจ้งข้อผิดพลาดจะเปิด GitHub เมื่อคุณกดเท่านั้น

สำรองข้อมูล

ไฟล์สำรองอยู่กับคุณ โดยค่าเริ่มต้นไฟล์จะเข้ารหัส AES-256 ด้วยวลีรหัสผ่านของคุณ

ลบข้อมูล

ไปที่การตั้งค่าแล้วเลือกลบข้อมูลทั้งหมดในอุปกรณ์ หรือใช้เมนูล้างข้อมูลเว็บไซต์ในเบราว์เซอร์
