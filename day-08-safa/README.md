# safa. — Clear time. Clear soul.

The silent spiritual instrument: no ads, no data collection, no guilt. Brand + V1 MVP concept page with a live four-tab phone demo, in one HTML file (Google Fonts only).

- **Today**: prayer times computed on device for 17 cities (UOIF, MWL, ISNA, Umm Al-Qura), live countdown, Hijri date, ± minute offset, Qibla bearing, mark-as-prayed.
- **Quran**: Al-Fatiha 1–4, Mushaf / word-by-word toggle, hide-words memory mode, tap-to-hear word audio and verse loop at 0.75–1.5× (streamed from public Quran.com audio).
- **Duas**: search by feeling, transliteration toggle, source badge, 33× counter.
- **Track**: weekly grid, pause mode that keeps the streak, evening reminder setting, JSON backup export.
- **Flight mode**: prayer start times along a great-circle route, in both time zones.

Unfinished: web demo only (no widgets, notifications or compass sensor), six example duas whose references need scholarly review, simplified solar model instead of adhan-js, tracker stored in this browser only.
