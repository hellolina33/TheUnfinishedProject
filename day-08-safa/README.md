# safa. — Clear time. Clear soul.

The silent spiritual instrument: no ads, no data collection, no guilt.

- `index.html` — brand and concept page.
- `app/` — the app: an installable, offline-first web app (PWA). Vanilla ES modules, no build step, no server, no account.

## App

| Tab | What works |
|---|---|
| Today | Prayer times computed on device (adhan-js), 16 methods, Asr madhab, per-prayer minute offsets, countdown, Gregorian + Hijri date, mark as prayed, Qibla compass (device sensor), flight mode |
| Quran | 114 surahs, Uthmani text, word-by-word meanings, two translations, verse transliteration, Mushaf flow, search by name / reference / word, Juz, favourites, resume, verse and word audio, loop a verse or a range, 0.75–1.5×, hide words to self-test, concise tafsir and circumstances of revelation |
| Duas | Full Hisnul Muslim (131 chapters, 266 invocations), search by feeling, Arabic / transliteration / translation, counter, audio, favourites, source badge |
| Track | Weekly view without percentages, pause mode, evening check-in, calendar export, settings, JSON backup export / import |

Languages: English and French (automatic from the phone, or set in Settings). French covers the whole interface, dates, surah names, two Quran translations (Rashid Maash, Hamidullah), French search, and 249 of 266 duas with French transliteration. Word-by-word meanings and tafsir stay in English.

All state lives in `localStorage`. A service worker caches the shell and every text file opened; audio can be saved per surah.

## v2 (Nov 2026)

Recitation player: one timeline per surah from 0:00, lock-screen controls (Media Session), basmala prelude, and a word-by-word colour sweep driven by quran-align timings (7 reciters, CC BY 4.0). Offline audio per surah, juz or whole Quran. Hijri calendar with key dates and moon-sighting offset. First steps (wudu, salat). French word by word (Dr Usama Nonnenmacher, CoranMot). Make-up prayers (qada). Six tafsirs with side-by-side comparison. Memorisation plan with spaced review. Khatm planner on the 604 Madinah pages. Hadith grade on each dua. Friday Al-Kahf reminder. Personal duas with reminders. Five Quran words a day. Themes, text size, contrast, reduced motion. Encrypted device-to-device sync file (AES-GCM, PBKDF2). Arabic interface (RTL). Sourced answers (word matching over translations and Hisnul Muslim; no generated text). Home-screen shortcuts.

## Data

`app/data` is generated by a script from open datasets: quran-json (text, CC BY 4.0), Quran.com word-by-word data, fawazahmed0/quran-api (Talal Itani, Pickthall), spa5k/tafsir_api (Al-Mukhtasar, Al-Wahidi), hisnmuslim.com (Hisnul Muslim), city-timezones. Licences for translations and tafsir must be confirmed before a store release.

## Unfinished

Not a native build. No widgets. No notifications while closed. Audio and offline audio untested on real devices. About half of the dua references are matched automatically and all need scholarly review.

### Version thaïe

L’interface, les guides, les parcours, la FAQ et les significations des douas sont disponibles dans la langue « ภาษาไทย ». Les textes propres à Safa sont en cours de relecture humaine. Les liens de signalement dans Apprendre permettent d’indiquer la page et le passage à corriger.

Le Coran utilise la traduction thaïe du King Fahad Quran Complex, référencée par [Tanzil](https://tanzil.net/trans/). Les textes de la copie [Quran API](https://github.com/fawazahmed0/quran-api/blob/93e6f64925ae76273520d636fcaaf061129f2316/editions/tha-kingfahadquranc.min.json) sont servis sans modification, par référence de sourate et d’ayah. Le commentaire distinct [Al-Mukhtasar (thaï), v1.0.0](https://quranenc.com/th/browse/thai_mokhtasar), du Tafsir Center for Quranic Studies, est fourni en ligne par QuranEnc. Les gloses mot à mot restent indisponibles en thaï.
