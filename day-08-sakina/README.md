# Sakina — compagnon spirituel zéro pub et 100 % privé

Page de présentation d'un concept d'app islamique, construite à partir d'une analyse d'avis négatifs (App Store, Google Play, Reddit) sur les apps existantes.

Un seul fichier HTML, sans dépendance hors Google Fonts. Trois démos fonctionnelles :
- Lecture mot à mot d'Al-Fatiha (versets 1 à 4), arabe seul ou mot à mot.
- Mode avion : heures de début des prières pendant un vol (route en grand cercle, position du soleil minute par minute).
- Suivi des prières avec mode Pause qui ne casse pas la série (stocké dans le navigateur).

Ce qui n'est pas fini : audio par mot, récitation IA, tafsirs, douas, Iqamah, assistant sourcé. Le mode avion ignore l'altitude de croisière.
