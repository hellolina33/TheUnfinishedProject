# Yes Man design

A warm, readable writing desk beside an oxblood amphitheatre. Preserve the two lecterns, original stage drawing and challenge identity. Ivory #fffaf1, ink #2a2322, wine #48202b, deep #28191f, brass #d3ac78. Georgia headlines; native system UI text. Body 16px, secondary minimum 12px; all control targets 44px. No decorative gradients, nested cards, fake metrics or glowing status dots.

Prioritize the received request, user intention and boundary. Reveal context/style settings on demand. Three navigation steps: decide, write, rehearse. Reading modes, all four intentions and useful stage summaries. Mobile has one main scroll, accessible keyboard area and conditional sticky actions. Language changes never rewrite user text or existing AI replies. No forced onboarding or sign-up.

Voice, persistence and sharing require explicit actions. Local data is opt-in. Offline models are clearly labeled. Practice is not a judgement of personality. The provider key is never exported, persisted or logged.
