# Yes Man · Day 06

Paste a request, choose a decision and define a boundary. Compare four editable responses, then rehearse up to five follow-ups. English and French interface and independent reply language.

The two HTML files are identical self-contained apps. Local templates are the default. Free AI sessions use the fixed-purpose Vercel endpoint, with up to 20 successful operations in 30 minutes per session. Provider failures and invalid output do not consume a session. The existing daily cap and best-effort instance limits still apply. An optional personal Gemini key stays in tab memory. Drafts and phrases are stored locally only when enabled. Voice and installation depend on browser support.

The service worker caches the application shell and icons, never API requests. The HTML download works with local templates without installation.

See [UX coverage](UX-COVERAGE.md) for the 100-item implementation map. The repository's existing browser checks include the Day 6 tests.
