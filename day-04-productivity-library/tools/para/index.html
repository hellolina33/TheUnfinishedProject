PARA Method

Organise digital information by actionability rather than by abstract topics.

Expected result

Four folders organised by actionability.

Fictional worked case

A redesign team stores active files, budget procedures and old website assets together.

The redesign is a project because it ends. Budget management stays an area. Navigation references can support future work and the 2025 version is archived.

The redesign is a project with an end. Budget management stays active as an ongoing responsibility.

Steps

  1. Sort files into active Projects, ongoing Areas, reference Resources and Archives.
  2. Move completed projects into Archives.
  3. Review active projects before creating new folders.

Review

Ask a teammate to find the current mock-up and the 2025 version without help.

Limitations

File by where you will use the item next. A topic alone rarely tells you whether it belongs in an active project.

Tiago Forte, Building a Second Brain (2022).
