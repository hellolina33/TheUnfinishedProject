ABCDE Method

Rank tasks by the consequences of not doing them: A is essential, E can be eliminated.

Expected result

A list ranked by the consequences of leaving each task undone.

Fictional worked case

A grant application closes today. The team has a morning for edits, attachments and room logistics.

Missing the submission deadline costs eligibility, so it is A. Reviewing attachments matters but follows submission readiness. Booking the room can go to a colleague and the duplicate can disappear.

The application has a deadline. Cosmetic changes can wait, and a duplicate task can go.

Steps

  1. Write every task before ranking.
  2. Give each task A, B, C, D or E based on its consequences.
  3. Finish A tasks before touching B tasks.

Review

Check that the application was sent before spending time on formatting.

Limitations

If several items are A, rank them A1, A2 and so on so the list still gives you a first action.
