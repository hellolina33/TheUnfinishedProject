Kaizen

Make small, continuous improvements that compound instead of waiting for a dramatic redesign.

Expected result

One small change, a simple measure and a reusable standard if it works.

Fictional worked case

A team spends several minutes each day hunting for the current template across folders.

The team searches several folders for the same template. Put the current version in one shared folder, time five searches and publish the convention if search time falls.

Put templates in one folder and time how long they take to find before publishing the convention.

Steps

  1. Find a tiny daily friction in your work.
  2. Test one small change.
  3. Keep it if it helps and repeat the cycle.

Review

Time five template searches before and after introducing a single shared folder.

Limitations

Change one part of the process at a time so you can tell what helped.

Masaaki Imai, Kaizen: The Key to Japan's Competitive Success (1986).
