Regret Minimization

Places a large decision on a long time line, so the question becomes which regret you would rather avoid.

Expected result

A choice or small reversible experiment informed by likely regrets.

Fictional worked case

Someone wants to offer a workshop but fears committing to a series before testing demand.

Regretting never trying the workshop is plausible. One small session tests the idea while limiting what you commit to if it is a poor fit.

If the likely regret is never trying, test a small version of the workshop before committing to more.

Steps

  1. Imagine you are 80, looking back on this decision.
  2. Ask which choice you would regret not making.
  3. Write the answer in one sentence, then check it against the facts.

Review

Run one small session and compare the experience with the feared outcome.

Limitations

Consider regrets on both sides, including commitments you would have to give up.

Often attributed to Jeff Bezos, who described it in interviews. No written source.
