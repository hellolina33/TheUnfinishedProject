What is still unfinished

  • Fifty tools so far. The first plan was closer to a hundred; more families can follow.
  • Some origins have no verified author. Where that is so, the source line says it, rather than naming someone.
  • Templates are .pptx files built in your browser. Google Slides can import them; they are not native Slides files.
  • Diagrams show the shape of each tool, not every step. Redraw them if you change the structure.
  • No account, no server, nothing you type is sent anywhere. That also means there is no feedback loop yet.
