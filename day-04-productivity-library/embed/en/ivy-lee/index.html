Ivy Lee Method

Ends the day with six ranked tasks, so the next morning starts without a choice to make.

Expected result

A ranked list of six tasks ready for tomorrow.

Fictional worked case

Six launch tasks compete for a developer’s attention. Checkout is the first dependency for the release.

Testing checkout is first because receipt testing depends on it. At the evening review, move unfinished icon work onto tomorrow’s list only if it still deserves a slot.

Checkout stays first until it passes. Move unfinished icon work to tomorrow’s ranked list.

Steps

  1. Each evening, write the six most important tasks for tomorrow.
  2. Rank them from 1 to 6.
  3. Next morning, work on task 1 until it is done before opening task 2.
  4. Move anything unfinished to tomorrow's list.

Review

At 5 pm, record what passed and move unfinished items to tomorrow in order.

Limitations

Treat the list as a ranking, not a promise to finish six items regardless of size.
