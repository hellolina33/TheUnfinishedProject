Parkinson’s Law

Set deliberately bounded time for tasks because work can expand to fill the time available.

Expected result

A shorter time limit checked against a quality standard.

Fictional worked case

Weekly meeting minutes take an hour. Most of the value comes from recording decisions and owners.

Compare the 25-minute minutes with the hour-long version. If both capture decisions, owners and dates, the extra time may add little value.

Check that the 25-minute version still captures the same decisions as the 60-minute version.

Steps

  1. Estimate the minimum useful time for the task.
  2. Set a deadline and define what 'good enough' means.
  3. Stop when the timebox ends and review the result.

Review

Compare both versions against the same decision checklist.

Limitations

Hold the output standard constant while you change the deadline.

C. Northcote Parkinson, 'Parkinson's Law', The Economist (1955).
