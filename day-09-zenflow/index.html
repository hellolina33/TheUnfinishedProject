What’s still unfinished

  • Web SpeechSynthesis voice quality varies widely across browsers and operating systems — some devices sound warm, others noticeably robotic.
  • The soundscape mixer is 100% procedural Web Audio (zero external files, instant load), so it lacks the acoustic micro-texture of studio-recorded singing bowls or real rain.
  • Direct browser BYOK calls to Anthropic may be blocked by CORS in some browsers without a proxy; Gemini, OpenAI, and the built-in offline script crafter work right out of the box.
  • Session history lives only in your browser’s localStorage (with JSON export/import backup) — no cloud sync or calendar reminders yet.
